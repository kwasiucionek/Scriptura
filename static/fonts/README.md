# Scriptura Serif

Self-hosted **EB Garamond**, normal and italic, variable weight 400–800.
Supports Polish diacritics and Greek; Hebrew uses the reader's system fallbacks.
No font requests are made to Google or another third party at runtime.

Source: [Google Fonts, `ofl/ebgaramond`](https://github.com/google/fonts/tree/7085eb89a950e85db5b166b7a58d414544b4140c/ofl/ebgaramond),
commit `7085eb89a950e85db5b166b7a58d414544b4140c`.
`EBGaramond[wght].ttf` and `EBGaramond-Italic[wght].ttf` were converted to WOFF2
with fontTools, without subsetting or altering glyphs.
